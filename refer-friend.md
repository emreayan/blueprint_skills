# Refer-a-Friend

## Ne zaman
Viral growth, customer rewards.

## Stack
Next.js + Supabase + email

## Süreç
1. Unique referral code
2. Share buttons (email, WhatsApp, SMS)
3. Friend signup → reward both
4. Reward tracking (credit, discount)
5. Leaderboard (gamification)
6. Email reminders
7. Anti-fraud

## Çıktı standardı
- Share-friendly (preview image)
- Mobile sharing native
- Reward instant (or post-conversion)
- Leaderboard updates daily

## Yaygın hatalar
- Reward fraud (fake accounts)
- Share UX kötü
- Both-side reward unutmak
