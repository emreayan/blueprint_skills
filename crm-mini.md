# Mini CRM

## Ne zaman
Solo founder, freelancer kendi müşteri yönetimi.

## Stack
Next.js + Supabase

## Süreç
1. Contact CRUD
2. Pipeline stages (lead → qualified → proposal → won/lost)
3. Drag-drop kanban
4. Activities (email, call, note)
5. Deal value + probability
6. Reports (conversion, velocity)
7. Email integration (Gmail/Outlook)

## Çıktı standardı
- Quick-add contact
- Mobile pipeline view
- Activity timeline per contact
- Won/lost analysis

## Yaygın hatalar
- Çok karmaşık (HubSpot olmaya çalışmak)
- Email sync delay
- Duplicate contact
