# AI Content Writer

## Ne zaman
İçerik üreticilere AI yardımcısı.

## Stack
Next.js + Anthropic + template library

## Süreç
1. Template seç (blog, email, ad copy)
2. Brief input (topic, audience, tone)
3. AI ile draft
4. Edit / regenerate sections
5. Tone adjuster (formal, casual, witty)
6. Plagiarism check (Copyscape API opsiyonel)
7. Export (Markdown, HTML, Google Docs)

## Çıktı standardı
- Streaming generation
- Tone consistency
- SEO suggestions
- Word count target

## Yaygın hatalar
- Generic output (template specifik olsun)
- No personality (system prompt detaylı)
- Hallucination (fact check uyarısı)
